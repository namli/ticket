# Глоссарий

Документация проекта использует каждый термин только в одном значении.
Не заменяй термин синонимом.

## Тикеты

| Термин | Значение |
|---|---|
| Проект | Каталог с подкаталогом `.tickets/` |
| Тикет | Файл `.tickets/<id>.md` |
| Front matter | Блок полей в начале тикета между двумя строками `---` |
| Блок текста | Одна из трёх частей тикета: описание, `Design`, `Acceptance Criteria` |
| Заметка | Запись с отметкой времени в разделе `Notes` тикета |
| Блокер | Незакрытый тикет, от которого зависит другой тикет |

## Веб-доска (`tk web`)

| Термин | Значение |
|---|---|
| Доска | Страница с колонками тикетов |
| Дорожка | Горизонтальная полоса доски с тикетами одного проекта |
| Колонка | Вертикальная группа тикетов одного состояния |
| Карточка | Блок одного тикета в колонке |
| Файл настроек | Файл TOML со списком проектов |
| Снимок | Данные одного проекта в памяти сервера |
| Отпечаток каталога | Набор троек: имя файла, время изменения, размер |
| Наблюдатель | Поток сервера, который раз в секунду сверяет отпечаток каталога |
| Конфликт правки | Название или блок текста изменился на диске после открытия формы |
